# leetcode

Java solutions to LeetCode problems.

## Requirements

- **JDK 21** (Eclipse Temurin 21.0.13)
- Maven 3.9+

### Java Home

```bash
export JAVA_HOME=/Users/varunsharma/Library/Java/JavaVirtualMachines/temurin-21.0.13/Contents/Home
export PATH="$JAVA_HOME/bin:$PATH"
```

Verify:

```bash
java -version
# openjdk version "21.0.13" ...
```

## Build

```bash
mvn clean compile
```

## Run tests

```bash
mvn test
```
