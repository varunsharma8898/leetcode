# Mobile revision writeups

Short notes for phone reading, grouped by pattern.

Open on GitHub mobile, or clone and browse in any markdown reader.

## How to use on mobile

1. Pick a pattern below → open a note.
2. Read **Problem** + **Intuition** only; re-derive the rest.
3. Check **Approach** / **Pitfalls**; open the linked `.java` if stuck.
4. Skim **Variations** for interview follow-ups.
